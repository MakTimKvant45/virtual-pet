# Виртуальный питомец

Консольная игра-тамагочи на Python 3. Ухаживайте за питомцем, следите за его состоянием и наблюдайте за его развитием!

## Описание

Программа позволяет выбрать одного из четырёх питомцев (кот, собака, дракон или робот), дать ему имя и ухаживать за ним. Каждый тип питомца имеет уникальные стартовые бонусы. По мере ухода питомец проходит стадии развития: **малыш → подросток → взрослый**. Если плохо за ним ухаживать — он заболеет и может "уйти из жизни".

### Особенности:
- 4 типа питомцев с разными характеристиками
- Система эволюции по возрасту и состоянию
- Случайные события (нашёл игрушку, разбил вазу и т.д.)
- Визуальные прогресс-бары для отображения состояния
- Обработка граничных случаев (перекорм, негативные значения)

## Инструкция по запуску

1. Убедитесь, что установлен Python 3.6 или выше
2. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/MakTimKvant45/virtual-pet.git
   cd virtual-pet
   ```
3. Запустите программу:
   ```bash
   python main.py
   ```
4. Следуйте инструкциям в меню
